## 3. A7NUX2sN — 학습 준비 §3 → 학습 → §1
### 3-1. 왜 이 판인가
- A7NUX2s(542 = 0)에서 542 화자 A칸 감정이 돌아왔습니다(9 step 평균 32 → 42%).
- 그런데 542 를 빼면서 **무감정 비율도 10.7 → 8.05% 로 함께 줄었습니다.** 그래서 원인이 둘 중 무엇인지 모릅니다.
  - (가) 542 지름길: "낭독 목소리 ref → 늘 무감정 정답" 행이 모델에게 "이런 목소리면 무감정으로" 를 가르침
  - (나) 무감정 비율: 그냥 무감정 연습이 줄어 감정 연습 비중이 커진 것
- **A7NUX2sN 은 542 를 빼고, 그 자리를 A7N · A7NU 의 무감정 정답으로 채운 판**입니다.
  - 행 수 206,570 · 무감정 비율 10.69% → **A7NUX2Rs6(206,570 · 10.7%)과 같습니다.**
  - 다른 점은 "무감정 행 5,941개가 542 화자인가(Rs6), 감정 데이터 화자인가(sN)" 하나뿐입니다.

### 3-2. 데이터(q3tts 세션이 만듦 · ✅ `_READY` 있음)
- 경로: `~/workspaces/preprocessed/vox_koft/A7NUX2sN/{train.jsonl, val_xref.jsonl, dataset_info.json, _READY}`(+ q3tts 쪽 같은 이름)
- 만든 코드: `tools/make_a7nux2rs6.py --n542 0 --neu_fill`
- 내용
  - A7NUX2s 의 모든 행 + **무감정 정답 5,941개에 같은 규칙으로 두 번째 ref**(5,941 = A7NUX2Rs6 의 542 행 수)
  - 추가 행: A7N 5,506 · A7NU 435 · 화자 53명 · ref 종류 A 3,405 / B 2,536
    - 무감정 정답의 ref 는 규칙상 다른 칸이라 **추가 행의 ref 는 모두 감정(A · B) 녹음**입니다. 542 행은 무감정 ref → 무감정 정답이었으므로, 이 차이도 보고서에 적어 주세요.
  - 검사 8개 모두 0 · A7NUX2s ⊂ A7NUX2sN · A7NUX2Rs6 의 542 아닌 행 ⊂ A7NUX2sN · val_xref = A7NUX2Rs6 것과 같음(cmp) · 두 프로젝트 사본의 (정답, ref) 순서 같음
- 받으면 확인할 것: checks 0 · 행 수 206,570 · 소리 파일 무작위 20개가 열리는지

| 데이터 | 행 | 542 행 | 무감정 비율 |

| A7NUX2Rs6 | 206,570 | 5,941 | 10.7% |
| A7NUX2s | 200,629 | 0 | 8.05% |
