  - 다만 **중립은 REF 쪽, 감정은 다른 쪽으로 갈 위험**이 있어 측정으로 확인해야 합니다.

## 1. D 재측정에 중립(Neutrality) 칸 추가
- 같은 16명 · 같은 seed 1986 · 같은 합성 방식(Controllable cloning: `"(지시문)문장"` + 목표 화자 무감정 reference · prompt 없음)으로, **중립 문장 2개 × 16명 = 32개**를 모델마다 만듭니다.
  - 지시문: `configs/emotion/a7n_vox_v1.yaml` 의 Neutrality 문구(학습 형식 그대로).
  - 문장: A7N val 의 Neutrality 문장 중 학습에 없는 것 2개(다른 칸 문장 고르는 규칙과 같게).
- 모델: 원본 + 18개 모델 전부(또는 시간이 많이 걸리면 원본 + 청음 페이지 열 4개 + 아래 3절 상위 5 · 이유 기록).
- 채점: 다른 칸과 같은 잣대(목표 1위 WavLM/ERes2Net · 목표 유사도 · e2v · arousal · CER · 깨짐 · 이상). 진짜 녹음 중립 기준선도 칸에 함께 넣습니다.
- 청음 페이지: 감정 6칸 앞에 **중립 칸**을 추가합니다(행 = 16명, 버튼 판정 · CSV 그대로). 숫자 · 표 · 요약도 7칸으로 늘립니다.

## 2. 가상 화자 일관성 측정(사용자 아이디어 검증)
- 질문: "모델 M 이 목표 화자 T 로 만든 **중립 + 감정 6칸이 서로 같은 목소리인가**?" — REF 와 같은지(지금까지의 잣대)와는 **별개**로 잽니다.
- 잣대(제안 · 더 나은 방법이 있으면 이유와 함께 바꿔도 됨)
  1. **세트 안 1위**: M·T 의 각 감정 출력이 같은 성별 후보(16명 각자의 M 생성 중립 평균 + 542 처음 보는 화자 진짜 녹음) 중 **자기 화자(T)의 M 생성 중립 평균에 가장 가까운** 비율. 진짜 녹음(같은 사람 감정 vs 무감정)도 같은 방식으로 재서 천장으로 씁니다.
  2. **공정한 잣대 방식**(감정끼리 비교): q3tts_koft `tools/diag/fair_timbre_probe.py` 의 생각(감정 착시를 빼려고 같은 감정끼리 비교)을 참고합니다. 감정 칸마다 "T 의 감정 출력이 다른 화자의 같은 감정 출력들보다 T 의 중립에 가까운가".
  3. 유사도 숫자: 중립 ↔ 감정 평균 cos(WavLM-large · ERes2Net 두 잣대), 그리고 REF ↔ 중립 · REF ↔ 감정과 나란히.
- 결과 표(모델 × 잣대)와 화자별 표(16명, `aihub_0110` 표시)를 만듭니다. 판정은 이 셋 중 하나입니다.
  - "REF 와 다르지만 세트 안에서 일관" → 생성 중립을 ref 로 쓰는 D안 가능
  - "중립만 REF 쪽" → 섞임 위험
  - "둘 다 아님"
- `aihub_0110` 처럼 REF 와 이질적인 화자는 **REF 음향 점검**을 합니다: 길이 · 볼륨(RMS/LUFS) · 잡음(SQUIM) · 대역폭(유효 주파수 상한) · 클리핑 · 무음 비율 · 말투. 16명 분포 안에서 튀는 값을 표시하고, 원인 가설은 "가설"로 적습니다.
