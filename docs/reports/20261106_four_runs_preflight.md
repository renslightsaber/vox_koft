## 8. 실행 방식 — 4개 연속 (`scripts/runs/20261106_A7N_4runs.sh`)
| 방식 | 앞 run 실패 시 | Ctrl-C 를 누르면 |
|---|---|---|
| `a && b && c && d` | 뒤 run 이 **모두 시작 안 함**(밤새 1번이 죽으면 나머지도 안 돔) | 멈춤 |
| `a ; b ; c ; d` | 다음 run 으로 넘어감 | ⚠️ 지금 run 만 멈추고 **다음 run 이 시작될 수 있음**(accelerate 가 Ctrl-C 를 받아 보통 종료 코드로 끝나면 셸은 "실패"로만 봄) |
| **연속 실행 스크립트(권장)** | 다음 run 으로 넘어감 | **전체 중단**(지금 run 이 끝나면 뒤 run 은 건너뜀) |
- 스크립트가 더 하는 일
  - 각 run 시작 전 **GPU 2,3 에 다른 프로세스가 있으면 멈춥니다**(최대 60초 기다린 뒤 · `--force` 로 무시). 남의 학습을 OOM 시키지 않기 위해서입니다.
  - `--from N` 으로 N 번째부터 다시 시작할 수 있습니다.
  - 끝나면 run 별 rc · 시간 요약을 보여 줍니다.
- 가짜 학습으로 시험한 결과(00:11~00:12)
  - A: 2번이 실패해도 3 · 4번이 진행됐습니다.
  - B: 3번 도중 프로세스 묶음 전체에 SIGINT(Ctrl-C)를 보내자 3번이 멈추고 4번은 "건너뜀(중단)"이 됐습니다.
  - `--from 3` 도 확인했습니다.
- 고친 버그: 처음엔 run 을 `&` 로 띄웠습니다. 비대화형 셸에서는 그렇게 띄운 자식이 SIGINT 를 무시해서 Ctrl-C 가 학습을 멈추지 못합니다 → 포그라운드 실행으로 고쳤습니다.
