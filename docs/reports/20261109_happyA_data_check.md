## 한 줄 답
**정답 녹음은 기쁘게 들립니다. 이름표가 흐린 것이 아닙니다.** 그래서 §5(기쁨A 고르기 판 A7NUX2sNph)는 **하지 않았습니다.**
- 무감정처럼 들리는 기쁨A 녹음은 **3.5%** 입니다(기준 30%).
  - "무감정처럼 들리는 녹음"의 정의: e2v 1위가 neutral 이고 happy 확률이 0.2 보다 낮은 녹음.
  - 화자별로 봐도 30% 를 넘는 화자가 없습니다(72명 중 0명 · 가장 높은 화자 25%).
- 약한 쪽은 **모델**입니다. NUX2sN s3000 의 기쁨A 출력은 데이터보다 훨씬 덜 기쁩니다.
  - e2v happy: 데이터 70% · 모델 53%
  - 무감정처럼 들리는 비율: 데이터 3.5% · 모델 38%
  - 같은 모델의 중립 출력과 비교해도 차이가 작습니다.
    - arousal(흥분도)은 중립 출력과 똑같이 0.52 입니다. 데이터의 기쁨A 는 같은 화자 무감정보다 +0.11 높습니다.
    - 높이는 REF 대비 +1.5반음입니다(중립 출력은 +0.4). 데이터 기쁨A 는 같은 화자 무감정보다 +2.9반음 높습니다.
- 뜻: 모델은 기쁨A 에서 "조금 밝은 중립"을 냅니다. 데이터가 가진 흥분도와 높이를 절반쯤만 따라갑니다.
  - 그래서 데이터에서 녹음을 골라내도 나아질 가능성이 낮습니다. 데이터 판보다는 **다른 모델의 기쁨A 를 섞는 쪽**(→ [REF 유사도 조사](20261109_ref_similarity_by_cell.md) (라))이나 지시문 쪽이 맞습니다.
