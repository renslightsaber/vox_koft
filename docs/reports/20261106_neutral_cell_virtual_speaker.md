## 3. 가상 화자 일관성 (사용자 아이디어)
### 3-1. 왜 재나
- q3tts 학습 데이터(D안)에 필요한 조건은 "**ref(중립)와 정답(감정)이 같은 목소리**"입니다. "진짜 REF 와 같음"은 필요하지 않습니다.
- 그래서 같은 모델 · 같은 목표 화자로 만든 7칸이 서로 한 사람이면 "가상 화자"로 쓸 수 있습니다.
- 위험은 중립은 REF 쪽으로, 감정은 다른 쪽으로 **갈라지는** 경우입니다.

### 3-2. 어떻게 재나 (`tools/vspk.py`)
- 잣대는 두 가지입니다: WavLM-large · ERes2Net. 순위는 두 잣대의 평균으로 매깁니다.
- 겨루기는 **같은 모델이 만든 같은 성별 목표 8명** 안에서 합니다(우연 = 12.5%).
- 지표 넷:
  - **(a) 세트 1위**: 감정 출력이 "자기 화자의 생성 중립 평균"에 다른 7명의 생성 중립 평균보다 가까운 비율
  - **(b) 감정끼리**: q3tts `fair_timbre_probe.py` 방식입니다.
    - 같은 묶음(중립 · 기쁨 · 슬픔 · 분노, A/B 합침)의 **다른** 출력 평균에 견줍니다.
    - 다른 화자도 같은 개수를 평균내고, 무작위로 3번 뽑아 평균합니다.
  - **(c) 천장**: 진짜 녹음 화자 16명(A7N 여8 · 남8)에 같은 구조로 같은 측정을 합니다.
    - 구조: REF 1 · 중립 2 · 묶음마다 4.
  - **(d) 갈라짐**: sim(생성 중립 평균, REF) − sim(생성 감정 평균, REF)
    - 진짜 녹음에서도 감정 때문에 생기는 차이가 있으므로, 그 값과 비교합니다.

## 6. 판단 — 가상 화자 D안: **조건부 가능** (숫자 근거 · 최종은 청음)

  1. **청음으로 확인** — 페이지 ②의 "세트" 버튼이 대부분 '같음'일 것.
  2. **REF 거르기** — 잡음 · 먹먹함 · 잘림 REF(`aihub_0109` · `0113` · `0110` 같은 것)는 빼거나 표시.

  4. 모델: 목소리 · REF 가까움은 **LoRA**, 감정 맞힘 · 중립다움은 **FT** 가 조금 낫습니다. 청음으로 고르기.
