## 한 줄 답
**대부분은 데이터대로 배운 것이고, 일부는 모델이 더 올린 것입니다.**
- 분노B 정답 녹음은 같은 화자의 무감정 녹음보다 **중앙 +5.4반음** 높습니다.
- 모델(A7NUX2sN s3000)의 분노B 는 REF 보다 **중앙 +7.9반음** 높습니다. 데이터보다 **약 2.5반음 더** 올립니다.
- 다른 칸은 모델이 데이터와 거의 같습니다(분노A 데이터 +2.6 · 모델 +2.0 · 기쁨B 데이터 +5.7 · 모델 +6.0).
- 그래서 대책은 두 갈래가 함께 필요합니다.
  - 넘치는 약 2.5반음: 문구 · 학습 쪽. 학습 ①(지시문 v3)이 이것을 봅니다.
  - 기본 +5반음: 데이터 쪽. 분노B 녹음 자체가 높으므로, 더 낮추려면 분노B 녹음을 골라 써야 합니다.

## 1. 무엇을 쟀나
- 대상: A7NUX2sN 학습셋(utt 중복 제거)에서 분노B 정답이 있는 화자 76명.
  - 그중 무감정 녹음이 있는 **69명**을 썼습니다.
  - 무감정 녹음이 없어 뺀 7명: a466_0001 · a466_0004 · a466_0029 · aihub_0004 · aihub_0036_ani · aihub_0060 · aihub_0061
- 비교 칸: 분노A · 기쁨B. (분노A 는 학습셋에 있는 화자가 42명뿐입니다.)
- 잰 값: 화자마다 "그 칸 녹음 F0 중앙값 − 같은 화자 무감정 녹음 F0 중앙값"(반음).
  - 무감정 녹음 = 학습셋 무감정 행 + 무감정 ref 풀(`A7N/ref_pool.jsonl`)
  - 화자마다 칸마다 최대 12개(seed 1986)
- F0 는 시험 A 와 같은 규칙으로 쟀습니다.
  - librosa pyin · 16kHz
  - 무감정은 60~800Hz 로 잽니다.
  - 감정 칸은 화자마다 [무감정 F0 / 2, 무감정 F0 + 20반음] 으로 좁혀 잽니다. 넓게 재면 남성 고함에서 배음을 잡기 때문입니다.
  - 유성 구간이 0.3초보다 짧은 녹음은 뺐습니다.
- 모델 쪽도 같은 규칙으로 쟀습니다.
  - D 재측정 음원(A7NUX2sN s3000 · 16명 · 칸마다 2문장)
  - 기준은 각 화자의 REF(무감정 reference)입니다.

## 4. 판단
- 지시문의 갈림길은 "데이터 중앙이 +6~7 이면 데이터대로, 훨씬 낮으면 모델 과장"이었습니다. 결과는 그 **사이**입니다.
  - 데이터 +5.4 → 모델 +7.9: 대부분(약 2/3)은 데이터 몫, 나머지(약 1/3)는 모델 몫입니다.
  - 다른 감정 칸은 모델이 데이터 높이를 거의 그대로 따라갑니다. 그래서 분노B 만 넘치는 것은 문구("Furious and shouting · loud")와 관련이 있을 가능성이 큽니다.
- 학습 ①(v3 문구 · `shouting · loud` 뺌) 결과는 [20261109_A7NUX2sN_iv3_results.md](20261109_A7NUX2sN_iv3_results.md) 에 있습니다.
- 데이터 쪽 대책(필요하면): 분노B 녹음 중 무감정 대비 +8반음 넘는 것(녹음의 25%)을 빼거나 줄이는 판.
