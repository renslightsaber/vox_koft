## 2. 학습 형식 확인 — reference 는 목소리 조건으로만 (코드 근거)
- 추론 "reference 만" 경로(`VoxCPM/src/voxcpm/model/voxcpm2.py:537-575`)의 입력 모양:
  `[103, ref_latent…, 104, "(지시문)문장" 토큰, 101]` → 그 뒤를 생성합니다. prompt 소리 · 전사문이 없습니다.
- 우리 학습 입력(`VoxCPM/src/voxcpm/training/packers.py:322-441` `process_tts_data_with_ref`) 모양:
  `[103, ref_latent…, 104, "(지시문)문장" 토큰, 101, 정답_latent…, 102]` — **앞부분이 추론과 똑같습니다.**
  - loss 는 정답 칸에만 걸리고, ref 칸 · 텍스트 칸에는 없습니다.
- prompt 이어 말하기(Ultimate cloning 의 `prompt_wav_path + prompt_text`) 모양은 학습에 **전혀 없습니다**.
  - `voxko/sft/trainer.py` 가 packer 에 `is_prompts=[False]*B` 를 넘기고, 데이터에 prompt 소리 · 전사문 필드가 없습니다.
- ref 는 **같은 화자의 다른 문장**(자기 자신 제외)입니다. 그래서 "ref = 목소리, 텍스트 앞 괄호 = 감정"을 배웁니다.
- 결론: **D안 목적과 맞습니다.**

## 3. ref 규칙 — 0.7 의 나머지 0.3 은 "ref 없음"
- 문장마다 · epoch 마다 `Random(seed|epoch|utt)` 로 정합니다.
  - 70%: 같은 화자 **무감정** ref 를 붙입니다. ref 풀에는 무감정만 있고, 다른 감정 ref 는 **절대 쓰지 않습니다**.
  - 30%: ref 없이 `"(지시문)문장"` 만 씁니다(Voice Design 모양).
- 무감정 녹음이 없는 화자 26명(train 7,308문장 · 6.9%)은 항상 ref 없음입니다. 그래서 실제 ref 비율은 약 **65%** 입니다(smoke 로그 `train/ref_frac`).
- 0.3(ref 없음)을 둔 까닭(공식 Voice Design 능력 유지 · 지시문 의존을 키움)은 가설이고 확인하지 않았습니다.
- D안 추론은 **항상 무감정 reference** 입니다. 그래서 학습도 항상 ref 를 붙이는 1.0 판이 더 직접적일 수 있습니다 → §4 후보 A.
