## 0. 한 줄 요약
**A7NX2R 은 "목소리 ↔ 감정" 맞바꿈 곡선을 넘어선 것이 아니라, 같은 곡선 위에서 목소리 쪽으로 옮겨 간 것으로 보입니다.** 그래서 감정이 약하게 들리면, 학습 설정보다 **데이터의 무감정 비율을 되돌리는 것**이 첫 번째 손잡이이고, 그 전에 **다시 학습하지 않고 해 볼 수 있는 추론 노브(CFG)** 를 먼저 시험해 보길 권합니다.

## 1. 학습은 어땠나
| 항목 | 의견 |
|---|---|
| 학습 자체 | 정상입니다. 4 run 모두 완주 · export 실패 0 · 설정이 백업과 같습니다. |
| 외우기 신호 | A7NX3(ref 3개 = 같은 정답 3번)는 처음 보는 화자 val 이 s750 뒤 꾸준히 오릅니다. A7NX2R(ref 2개)은 그 폭이 줄었고, lr 5e-5 판은 거의 평평합니다. **"정답 반복을 줄이자"는 수정은 의도대로 작동했습니다.** |
| lr | 5e-5 판이 감정 · CER · val 모두 조금 낫습니다. 1e-4 는 s500 부터 이미 목소리 쪽으로 기울었습니다. 다음 판도 **5e-5 를 기본**으로 권합니다. |
| val_xref | run 끼리 차이가 ±0.003 으로 잡음 수준이라, 이 잣대로는 run 을 가를 수 없습니다. |

## 2. 데이터셋 평가 — 같은 곡선 위의 다른 점
같은 평가(D 재측정 · 무감정 ref)에서 감정(e2v 6칸)과 목소리(목표 유사도)를 나란히 놓으면 이렇습니다.

| 모델 | 감정 e2v | 목표 유사도 | CER |
|---|---|---|---|
| LoRA01 s1500 | 52% | 0.650 | 2.2 |
| A7NX3 s2250 | 52% | 0.647 | 2.0 |
| **X2R02 s2000** | **54%** | **0.648** | 1.9 |
| LoRA01 s3000 | 57% | 0.637 | 2.2 |
| A7NX3 s4500 | 57% | 0.624 | 2.2 |
| X2R01 s4500 | 47% | 0.663 | 2.1 |
| X2R02 s4500 | 51% | 0.661 | 1.5 |

- X2R02 s2000 은 LoRA01 s1500 · A7NX3 s2250 과 **거의 같은 점**입니다.
- X2R01 · X2R02 s4500 은 감정을 내주고 목소리를 얻은 점입니다.
- 즉 숫자로는 **어느 데이터도 다른 데이터를 모든 면에서 이기지 못했습니다**(같은 맞바꿈 곡선).
- 참고로 e2v 6칸은 문장 192개라서 한 점의 오차가 약 ±3.6%p 입니다. 5%p 차이는 "아마 있음" 정도입니다.

**A7NX2R 이 감정을 잃은 이유(추정 · 큰 순서)**
1. **무감정 비율 14.5% → 23.2%**: 4,500 step 동안 감정 정답을 본 횟수가 A7NX3 보다 약 10% 적습니다(약 11만 vs 12.3만).
2. **542 는 낭독 녹음**: 1,000명이 "평평하게 읽는" 말투를 함께 가르칩니다. 목소리 일반화에는 좋지만 감정 쪽으로는 반대 방향입니다.
3. 음질 제외는 원인이 아닙니다. 빠진 1,509개는 칸마다 0.7~1.9% 로 고르게 빠졌습니다(분노가 특히 많이 빠지지 않음).

**좋아진 것(지켜야 할 것)**
- 감정 ref 판에서 ref 감정이 새어 나오는 비율이 LoRA01 28% → X2R01 19~22% 로 줄었습니다. 이것이 "다른 칸 ref"(X) 의 본래 목적이고, 실제로 작동하고 있습니다.
- 처음 보는 화자 목소리 1위가 지금까지 가장 높습니다(ERes2Net 96~98%).

## 3. 감정이 약하거나 목소리가 다르게 들리면 — 무엇을 바꿀까
| 들린 결과 | 권하는 순서 |
|---|---|
| **감정이 약함 · 목소리 OK** | ① 다시 학습하지 않고 **추론 CFG 를 올려 보기**(2.0 → 2.5 · 3.0, X2R02 s2000 · s4500) — 노트북에 `CFG` 노브가 이미 있음. CFG 가 지시문에도 걸리는지는 확인 필요 ② 그래도 약하면 **데이터 수정**: 542 는 화자 수(992명)를 지키고 화자당 문장만 12 → 6, A7N 무감정 정답은 ref 1개 → 무감정 비율 약 15%(A7NX 수준) · 542 비중 약 5% ③ 지시문 v2(더 센 문구)는 **마지막**: 서비스 쪽 지시문도 함께 바꿔야 해서 영향이 큽니다 |
| **목소리가 다름(특히 B칸)** | A7NX2R 의 장점이 사라진 것이므로 데이터 방향(X + 542)은 유지하고 **step 을 앞으로**(s1000~2000) 고르기. 다시 학습한다면 B칸 정답에 무감정 ref 비중을 늘리는 것(N 0.4 → 0.5)을 고려 |
| **둘 다 괜찮음** | X2R02 s2000 또는 s4500 을 후보로 · 데이터는 그대로 |

**학습 설정(lr · step · LoRA rank)은 첫 손잡이로 권하지 않습니다.**
- lr 를 올리거나 오래 학습하면 감정은 오를 수 있지만, 이 프로젝트에서 늘 보았듯 목소리가 같이 내려갑니다(곡선 위 이동).
- 곡선 자체를 옮기려면 **무엇을 보여 주느냐(데이터 비율)** 를 바꾸는 쪽이 맞다고 봅니다.

## 4. 그 밖의 제안
1. **감정 ↔ 목소리 그림 한 장**: 모든 run · step 을 (e2v, 목표 유사도) 점으로 찍으면 "곡선을 넘었는가"를 한눈에 볼 수 있습니다. 숫자 표보다 판단이 쉽습니다.
2. **감정 ref 판 청음 페이지는 작게(8줄 안팎)** 만들 만합니다. X 데이터의 본래 목적(ref 감정이 새지 않음)을 귀로 확인하는 유일한 방법입니다.
3. A7NX2R 두 판 재개용 파일 정리(약 17GB) — 사용자 요청(11/07)대로 진행합니다.
